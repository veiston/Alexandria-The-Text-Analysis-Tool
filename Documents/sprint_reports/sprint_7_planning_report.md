## Sprint Goal

To verify that Alexandria meets its functional and non-functional requirements, improve code quality, fix identified issues and prepare the application for final acceptance.

## Selected Product Backlog Items

- Acceptance Test Plan
- Test Plan
- User Acceptance Testing (UAT)
- SonarQube issues
- Static analysis workflow
- Bug and issue tracking
- Heuristic Evaluation

## Planned Tasks / Breakdown

### Test Planning

- Prepare the Acceptance Test Plan with acceptance criteria, a coverage matrix and test cases.
- Create the Test Plan describing the testing objectives, resources, environment and tasks.

### User Acceptance Testing

- Perform UAT based on the Acceptance Test Plan.
- Complete individual UAT reports.
- Prepare a combined results table and a short summary for the Sprint 7 Report.

### Static Analysis and Code Quality

- Fix SonarQube issues and achieve ratings of A or at least B.
- Fix the failing GitHub Actions static analysis workflow.
- Verify the final static analysis results.

### Bug and Issue Tracking

- Create and maintain a bug tracking table throughout the sprint.
- Record, fix and retest identified issues.

### Heuristic Evaluation

- Evaluate the application according to Nielsen's usability heuristics.
- Document the identified usability issues and evaluation results.
