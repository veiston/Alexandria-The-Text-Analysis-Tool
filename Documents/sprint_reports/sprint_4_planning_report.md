## Definition of Done

A Sprint 4 task can be moved to `Done` when:

- The planned functionality is implemented.
- The implementation has been tested.
- Known bugs related to the task are fixed.
- Code changes are committed and pushed to GitHub.
- The relevant Trello/Jira task is updated.
- UI changes are integrated into the application.
- Backend changes are connected to the frontend where required.
- The work is reviewed when applicable.
- The team member records the time spent on the task.

For the Sprint 4 deliverables to be considered complete:

- Main prototype functionality is finalized.
- Major bugs are fixed.
- Comparison functionality is integrated.
- Unit tests are completed.
- Code review is completed.
- End-to-end testing is completed or remaining issues are documented.
- Docker image is deployed and tested.
- Docker deployment results are documented.
- User guide is updated.
- GitHub repository is finalized.
- Trello/Jira is updated.
- Final presentation is prepared.
- Product walkthrough is prepared.
- Individual contributions are documented.
