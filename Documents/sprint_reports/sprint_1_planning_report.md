## Definition of Done

A Sprint 1 task can be moved to `Done` when:

- The planned work is completed.
- Required documents are added to GitHub.
- Trello is updated.
- The work is reviewed when needed.
- Required diagrams or designs are available.
- Code changes are committed to GitHub.
- The team member records the time spent on the task.

For Sprint 1 to be complete:

- Product Vision is ready.
- Product Backlog and user stories are ready.
- Story Points and priorities are added.
- Project Plan is ready.
- Technology Stack is documented.
- Figma design is ready.
- Use Case Diagram is ready.
- Initial database architecture is ready.
- GitHub and Trello are set up.
- Sprint 1 Report is prepared.
