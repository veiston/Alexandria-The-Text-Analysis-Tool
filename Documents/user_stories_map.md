## User stories map

| User activity | Epic | User story | Story points |
|---|---|---|---:|
| Analyse texts | Uploading and Viewing Text | As a user, I want to upload a text file so that I can analyze its content in the application. | 3 |
|  |  | As a user, I want to open an uploaded text in the application so that I can work with it. | 2 |
|  |  | As a user, I want to see the text together with analysis tools so that I can read the text and view results at the same time. | 5 |
|  | Text Search | As a user, I want to search for words and phrases in a text so that I can find needed places. | 5 |
|  |  | As a user, I want search to include different forms of the same word so that I can find all its occurrences. | 5 |
|  |  | As a user, I want to see found words and phrases together with surrounding text so that I can understand their context. | 5 |
|  |  | As a user, I want to see the location of found results in the text so that I can quickly return to the needed place. | 8 |
|  | Text Statistics | As a user, I want to see the most frequently used words in a text so that I can get general statistics. | 5 |
|  |  | As a user, I want to see the number of occurrences of a selected word or phrase so that I can get accurate data about its usage. | 3 |
|  |  | As a user, I want to exclude stop words from statistics so that I can see more meaningful words. | 3 |
|  | Text Comparison | As a user, I want to upload several texts so that I can compare them with each other. | 3 |
|  |  | As a user, I want to view selected texts at the same time so that I can understand which materials I am comparing. | 5 |
|  |  | As a user, I want to see common frequently used words in several texts so that I can find similarities between works. | 8 |
|  |  | As a user, I want to compare the number of occurrences of a selected word or phrase in different texts so that I can see differences between them. | 3 |
| Manage user profile | User Profile | As a user, I want to create a personal profile so that I can save my research materials. | 3 |
|  |  | As a user, I want to store my personal information so that I can manage my profile. | 3 |
|  | Saved Statistics | As a user, I want to save text statistics results so that I can return to them later. | 3 |
|  |  | As a user, I want to view saved statistics with information about the source text and date so that I can review previous analysis. | 5 |
|  | Saved Quotations | As a user, I want to save quotations from texts with source information and location so that I can use them later. | 3 |
|  |
